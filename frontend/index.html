What the API returns

1 · Asset response

The first response is intentionally small: an ID and processing state. Poll /assets/{id}/status while work continues.

{
  "id": "asset-id",
  "processing_state": "pending",
  "source_type": "url"
}

2 · Temporal evidence

Indexers attach evidence to time ranges. The UI can jump the player directly to the source.

{
  "start_ms": 55000,
  "end_ms": 75000,
  "modalities": ["visual"],
  "evidence": ["goal celebration"]
}

3 · Explainability chain

Every result should make the path visible: query → candidate → weighted score → merged range → clip.

query
  ↓
vector + full-text candidates
  ↓
weighted score (0.7 / 0.3)
  ↓
temporal merge + roll
  ↓
playable timestamp
